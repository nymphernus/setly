# Setly

Setly — трекер тренировок для Android, который берёт на себя скучную часть: считает норму, раскладывает её по подходам и показывает, когда удобнее тренироваться. Работает без интернета и регистрации. Аккаунт нужен только если хотите хранить данные в облаке.

Версия 1.0.0.

## Что умеет

- Составить тренировку на любой срок: задайте цель, число дней и время сна — Setly сам разобьёт норму на подходы.
- Показать их на больших аналоговых часах. У каждого упражнения свой цвет, сектор сна выделен серым, в центре — текущее время.
- Отмечать подходы одним нажатием. Никаких таймеров и общих «кругов»: просто отмечаете то, что сделали.
- Не терять пропущенное. Недоделанная норма плавно переносится на следующие семь дней.
- Хранить историю в календаре. Если забыли отметить подход, можно вписать фактические повторения прямо за нужный день.
- Давать трофеи за прогресс — 40 штук в трёх разделах: «Сила», «Дисциплина», «Особые».
- По желанию синхронизироваться через Google: объединить данные с облаком, сделать бекап и восстановиться из него.

## Как начать

1. Установите приложение и откройте вкладку **Тренировки**.
2. Нажмите «+», придумайте название, укажите, сколько дней длится цикл, и время сна.
3. Добавьте упражнения. Для каждого задайте норму на день и сколько раз делать в одном подходе.
4. Откройте тренировку. Сверху будут часы с цветными секторами, ниже — упражнения с чипсами подходов.
5. Нажимайте на чипсы по мере выполнения. Всё сохраняется автоматически, даже без сети.

## Где что найти

- **Тренировки** — ваши планы и отметки на сегодня.
- **Упражнения** — общий список, можно добавить своё или поправить существующее.
- **История** — календарь по месяцам и ввод фактических повторений.
- **Трофеи** — достижения, разложенные по разделам.
- **Профиль** — статистика, аккаунт, бекапы и настройки темы с уведомлениями.

Тёмная тема включена по умолчанию; поменять её можно в профиле.

## Про облако

Оно необязательно. Если войти через Google, данные можно:

- **Синхронизировать** — при слиянии сохраняется самая полная версия каждой записи.
- **Создать бекап** — снимок всех тренировок, упражнений и прогресса.
- **Восстановить** — выбрать нужную дату и вернуть все данные из бекапа.

В профиле всегда видно, когда была последняя синхронизация.

## Если хотите собрать сами

Приложение рассчитано на Android 10 и новее. Установите JDK 17 и Android SDK и выполните в PowerShell:

```powershell
$env:JAVA_HOME = 'C:\Program Files\Android\Android Studio\jbr'
.\gradlew assembleRelease
```
